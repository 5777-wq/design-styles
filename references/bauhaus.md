
# 包豪斯风格网页设计 (Bauhaus)

## 风格本质

一句话：**几何图形本身是主角——圆、方、三角按 Kandinsky 的色彩心理学配对，构成即内容。**

1919 年格罗皮乌斯创立于魏玛，纲领「艺术与技术的新统一」。Kandinsky 1923 年的问卷实验：多数人将**黄填三角、红填方、蓝填圆**——形状与色彩有固定心理学配对，这是包豪斯区别于任意「儿童色块拼贴」的理论根据。网页化的方向不是复古 1920s，而是「几何作为功能语言」。

**适用**：设计/建筑院校、美术馆、文化机构、创意品牌、工作室官网、活动海报页。
**不适用**：信息密度高的仪表盘与工具产品（那应该用 swiss-design）；严肃金融医疗（色彩能量过剩）。

## 与瑞士风格的分界（关键判据）

包豪斯：**几何是内容主角**，允许大面积色块、45° 旋转、构成主义斜线——栅格只是构图工具。
瑞士：几何退场为网格后台，信息层级是主角，无装饰图形、无旋转。

**网页判据（「瑞士测试」）：删掉所有几何色块后页面仍成立 = 做成了瑞士；删掉后信息崩塌、依赖色块才能表意 = 包豪斯。**

## 十二条铁律

1. **每屏至少一个「主角几何」**（圆/方/三角之一），几何是内容主角不是背景贴纸。
2. **形状-色彩按 Kandinsky 配对**：黄三角、红方、蓝圆；禁止随意混配（刻意「破格」每屏至多一处）。
3. **旋转只允许 45° 增量**，任意图层旋转不超过 ±45°——构成主义斜线体系。
4. **矩形直角、圆必须正圆**，不存在 8px 这类「中间态圆角」——柔和圆角会滑向 Material/幼儿园感。
5. **平涂无渐变、无投影光晕**，层级用硬阴影（`4px 4px 0` 实色）或规则线。
6. **色板锁定**：黑/米白 ≥80% 面积，单屏原色 ≤3 个，黄永远不做文字色（对比度不足）。
7. **展示字体用几何无衬线**（Jost / League Spartan，Futura 谱系），标题字号对比至少 3 倍级差。
8. **全大写标签 + 0.12em 字距**承担导航/眉题/按钮文字，呼应 Bayer Universal 单字表理想。
9. **粗黑规则线（2–4px）划分区块**，让网格本身可见——结构即视觉。
10. **构成不对称但平衡**：大色块偏置一侧，对侧用小几何或文字配重。
11. **每个几何元素承担功能**：三角=指向、圆=图标/数据点、方=卡片底；纯装饰几何每屏 ≤2 个。
12. **交互态用色反转而非圆角**：hover = 底色与文字互换或硬阴影位移 2px，保持几何纯度。

## 设计 Token 速查

**配色「经典三原色版」（默认）**：

| token | hex | 用途 |
|---|---|---|
| --red | `#E2001A` | 主 CTA、强调、Kandinsky「方」位 |
| --yellow | `#F5A800` | 高亮、次级强调（避开浅黄） |
| --blue | `#1D4E89` | 链接、信任区块、「圆」位 |
| --ink | `#111111` | 正文、规则线、大标题 |
| --paper | `#F5F1E6` | 页面底色（米白，非纯白） |

备选：「海报构成版」仅黑/红/米白（Joost Schmidt 1923 海报的史实配色，适合 hero 与深色区块）；「现代校准版」红 `#D7263D` / 黄 `#F2B705`（只作背景色块）/ 蓝 `#1A47B8` / 纸 `#FAF7F0`，正文对比度更友好。

**字体**（Google Fonts）：展示与正文首选 `Jost`（300–900，Futura 谱系最近复刻）；备选 `League Spartan`（更粗更墩，适合超大标题）；中文 `Noto Sans SC`（标题 700–900 / 正文 400）。
引入：`family=Jost:wght@300;400;500;700;900`

**字阶**：display 72–120px/900；h1 48px/700；h2 32px/700；h3 24px/500；body 16–18px/400，行高 1.5（标题 1.05），行长 60–72ch。全大写标签 letter-spacing 0.12em；≥80px 大标题 -0.02em。

**几何纪律**：矩形 `border-radius: 0`；圆 `border-radius: 50%` 且宽高相等；规则线 1px（细节）与 3–4px（分节）实线 `#111`；禁虚线/双线/渐变线；硬阴影 `4px 4px 0 #111`。

## 工作流程

1. **选色板**：三原色版（默认）/ 海报构成版（黑红米白，海报感 hero）/ 现代校准版（对比度优先）。
2. **从模板起步**：复制 `assets/templates/bauhaus.html`（虚构设计学校 KHA Formwerk 示范页），替换内容与配色方案。
3. **组装模式**：按 references/notes/bauhaus.md 的 6 个版式模式（Schmidt 海报 hero、色块导航、楔形分割带、几何卡组、规则线目录、数据几何徽章）拼装。
4. **过自检清单**，重点做「瑞士测试」。

## 自检清单

- [ ] 每屏有一个主角几何；删掉所有几何色块后页面会失去表意（通过瑞士测试）
- [ ] 形状与色彩符合 Kandinsky 配对（黄三角/红方/蓝圆）
- [ ] 所有旋转都是 45° 增量且 ≤45°
- [ ] 没有 1–99px 的中间态圆角；没有渐变；没有模糊阴影
- [ ] 黑/米白占 ≥80% 面积，单屏原色 ≤3 个，黄没有用作文字色
- [ ] 展示字体是几何无衬线（Jost 系），标题与正文有 3 倍级差
- [ ] 全大写标签 0.12em 字距；规则线只有 1px / 3–4px 两档实线
- [ ] hover 用色反转或硬阴影位移，没有圆角动画
- [ ] 移动端主角几何缩放不删减；色块导航折叠为全屏直角菜单
