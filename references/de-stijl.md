# De Stijl 风格派网页设计 (新造型主义)

## 风格本质

一句话：**把页面还原为「横线 + 竖线 + 三原色」的最小词汇表——贯通黑线为骨，白格为体，色块为事件。**

1917 年 Theo van Doesburg 创刊《De Stijl》得名；Mondrian 提供理论（《新造型主义》），Rietveld 提供三维实证（红蓝椅、施罗德住宅）。它不是装饰风格而是一套视觉语法——网页上所有「格子风」（含 Microsoft Metro）的祖先。

**适用**：美术馆、基金会、建筑与家具品牌、文档型站点、设计工作室——想表达秩序与严肃的场合。
**不适用**：需要图标插画（圆/三角）的页面（→ bauhaus）、情绪化消费品牌（→ glassmorphism/pop-art）。

## 与 bauhaus 的分界（同 skill 族的判据）

De Stijl 只有**正交 + 黑白 + 三原色**，无圆、无三角、无 45°、无旋转；bauhaus 有圆方三角基础形与斜向动势，气质更热。一句话判据：**页面里只要有一个图形需要圆或三角，选 bauhaus；全部视觉都能用横竖线段完成，选 De Stijl。**

## 十二条铁律

1. **只用水平线与垂直线**——对角线与曲线出现即不再是风格派。
2. **黑色分割线必须贯通到容器边缘，禁止悬空断裂**——贯通线是承重墙。
3. **全局仅 6 色：红、黄、蓝、黑、白、灰**——禁二次色、渐变、投影。
4. **任何两个彩色块不得相邻**——必须由黑线或白格隔开（Mondrian 硬规则）。
5. **色块非对称分布但整体平衡**——一个主色大块 + 若干小块；三色不必同时出现。
6. **白色是最大的颜色**——白格占画面 ≥50%，色块只是画面里的「事件」。
7. **直角统治一切：border-radius 一律 0**。
8. **黑线粗细全站不超过 3 档**（12/8/4px）——线宽即层级。
9. **用 CSS Grid 的 gap 画黑线**（容器铺黑、格子铺色）——结构上保证线永远贯通。
10. **正文住白格，颜色住导航与标识**——大段文字不压色块；黄块只放黑字短标题。
11. **等级靠格子面积与线宽表达**——面积即权重。
12. **断点之间保持行列次序**——塌缩不许打乱阅读顺序。

## 设计 Token 速查

**配色 A「正典纯白」（默认）**：红 `#DD0100`（可放白字）/ 黄 `#FAC901`（**必须黑字**）/ 蓝 `#225095`（白字 7.9:1）/ 黑 `#0D0D0D` / 白 `#FFFFFF` / 灰 `#8E8E8E`。
备选 B「米白纸感」：红 `#E30613` / 黄 `#FFD800` / 蓝 `#0247FE` / 纸 `#F9F5F0`。

面积配比：白 ≥60%、黑线 8–10%、三色合计 ≤25%、单色块 ≤35%。

**字体**：标题 `"Archivo Black"`；正文 `"Inter", "Noto Sans SC"`。红蓝块只放白色短词（≤2 词）；黑字首选白格或黄块；禁三色字、描边字。

**黑线体系**：12px 页首尾贯通线 / 8px 标准 gap / 4px 卡内分隔。实现：容器铺黑 + Grid gap 出线。

**色块尺寸**：桌面 ≥96×96px；主色块 ≤40% 视口宽；每屏色块 ≤3 个；构图 4–7 格为宜。

## 工作流程

1. **选配色**：正典纯白（默认）或米白纸感变体。
2. **从模板起步**：复制 `assets/templates/de-stijl.html`（虚构家具工作室「VML · Vorm en Lijn」示范页，整页用「容器铺黑 + gap 出线」实现），替换内容。
3. **组装模式**：蒙德里安导航 → 正典 Hero 构图（grid-template-areas）→ 章节画框 → 色块 KPI 条 → 不等分画廊 → Rietveld 交错页 → 封底构图页脚。
4. **过自检清单**。

## 自检清单

- [ ] 页面上没有任何对角线、曲线、圆角、旋转、斜切
- [ ] 全局只有红黄蓝黑白灰 6 色；无渐变、无投影
- [ ] 没有任何两个彩色块相邻；黑线全部贯通到边缘、无悬空
- [ ] 白格占 ≥50%；每屏色块 ≤3 个；三色合计 ≤25%
- [ ] 线宽只用 12/8/4px 三档
- [ ] 黄块上只有黑字短标题；红蓝块上只有白色短词；大段文字都在白格
- [ ] 层级全靠格子面积与线宽，没用下划线/斜体/花式按钮
- [ ] hover 只有 brightness 或线宽加重（≤150ms）；无 shadow 悬浮、无色块穿越黑线
- [ ] 移动端线宽降档但黑线不消失；色块最小 72×72px；阅读次序不变
