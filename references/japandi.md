# 日式侘寂 / Japandi 风格网页设计 (Wabi-Sabi / Japandi)

## 风格本质

一句话：**空间即设计——用极端的留白、明朝体与自然肌理制造「间」的心境，空白不是未完成，而是就绪状态。**

美学根源：侘寂 wabi-sabi（不完美 fukinsei、无常 mujō、朴素 koko）、间 (ma)——被赋予能量的主动间隔、原研哉《白》与「空」（不是 empty 而是 ready-state）、无印良品「这样就好」、隈研吾的粒子化材料。注意日本网页设计的两极：大众端（乐天式高密度链接墙）与高端端（一屏一意、低密度、明朝体）。**本规范只做高端极。**

**适用**：茶/酒/香/器物匠人品牌、温泉旅馆与酒店、美术馆与文化机构、和菓子/怀石料理、婚礼与摄影工作室。
**不适用**：SaaS 后台、资讯门户、工具产品、促销驱动电商（那些对应另一极）。

## 与瑞士风格的分界（同 skill 族的边界）

| 维度 | 瑞士国际主义 | 日式禅意 |
|---|---|---|
| 秩序来源 | 数学网格、客观 | 自然、不完美、余韵 |
| 留白目的 | 层级与视线引导 | 「间」的心境，空白即内容 |
| 字体 | 无衬线（Helvetica） | 衬线/明朝体 |
| 层级手段 | 色块、字重 | 细线、字距、留白 |
| 不对称 | 动态对角冲突 | 「均工」静平衡 |
| 肌理 | 禁止 | 必须（纸、木、噪点） |
| 节奏 | 快、锐利 | 慢、呼吸 |

两者共享「少」，分歧在「为什么少」。

## 十二条铁律

1. **任何一屏 ≥50% 空白**——空白是「间」，是邀请参与的就绪状态。
2. **一屏一意**——每个视口只承载一句主文案或一件事，密度主动压低。
3. **全站明朝体/衬线打底**，无衬线只做按钮、表单、标签。
4. **全站 ≤4 色**：纸底 + 墨字 + 一主点缀 + 一枚印章红；唯一允许的高饱和是印章红且面积 ≤32px。
5. **禁阴影、禁渐变、禁重底色块**——层级靠 1px 细线、字重与留白完成。
6. **直角优先（radius 0–2px）**，全圆仅限 ≤4px 圆点符号。
7. **竖排只做「落款」**：每页 ≤2 处、每处 ≤12 字，永远不做正文。
8. **不对称但静平衡**——元素错落但视觉重量均匀分布，不做对角张力构图。
9. **肌理代替装饰**——全局 3–6% 纸纹噪点；摄影一律自然材质 + 大量空景。
10. **动效慢半拍**——最短 400ms、全站 ease-out 淡入，禁弹跳与自动强轮播。
11. **季节感靠内容与摄影表达**，禁樱花/灯笼/和服贴纸插画——那是 cargo-cult 假和风。
12. **每块空白须能回答「这里空着是为了让什么呼吸」**——答不了就填内容或改构图。

## 设计 Token 速查

**配色 A「纸与墨」（默认，hex 经和色大辞典核验）**：

| 角色 | 色名 | hex |
|---|---|---|
| 底色 | 生成り kinari（和纸米白） | `#F7F3EC` |
| 卡面 | 胡粉 gofun | `#FDFCF8` |
| 主文字 | 墨 sumi | `#26231F` |
| 次级文字 | 鈍 nibi | `#6E6A61` |
| 细线 | — | rgba(38,35,31,.16) |
| 点缀 | 藍鼠 ainezu | `#6C848D` |

备选：B「茶土」（茶/食品类）利休茶 `#A59564`、黄土 `#C39143`、小豆 `#96514D`；C「朱印」（强调专用，小面积）臙脂 enji `#B94047`。

**字体**（Google Fonts）：中文主体 `Noto Serif SC`（200–500）；日文点缀 `Shippori Mincho` 或 `Zen Old Mincho`；西文 `Cormorant Garamond`（300 + italic）；无衬线辅助 `Noto Sans SC`（300/400）。栈：`"Cormorant Garamond","Noto Serif SC","Shippori Mincho","SimSun",serif`（西文先于中文）。

**字阶**：display（hero 竖排大字）72–120px，weight 300–400，tracking 0.35em；H1 40–48 / H2 28–32 / H3 20–22；正文 15–17px / 400，line-height 1.9–2.1，tracking 0.05em；西文小标签 10–11px，uppercase，tracking 0.25–0.35em。**禁 700+ 粗体**（明朝体粗体即「凶」），强调靠字号与留白。

**竖排（writing-mode）要点**：`writing-mode: vertical-rl`（正统日式）+ `text-orientation: mixed`；line-height 即列间距（2–2.4）；letter-spacing 变纵向字距（0.3–0.5em 出「落款感」）；数字纵中横排 `text-combine-upright: all`；限 max-height 控列长；只用于标题/短语/落款。

**线条与肌理**：hairline 1px solid rgba(38,35,31,.16)；重要分隔用双细线（间隔 3px 两条 1px）；印章 = 24–32px 方形臙脂块内反白 1–2 字，rotate ≤3°；全局纸纹 = SVG feTurbulence 噪点覆盖层，opacity 3–6%，multiply。

## 工作流程

1. **确认产品属于「高端极」**：匠人品牌/旅馆/文化机构才用本风格；高密度信息站改用 swiss。
2. **从模板起步**：复制 `assets/templates/japandi.html`（虚构京都茶庄「白鷺園」示范页，含竖排 hero、横线章节、小图大空、印章落款全套），替换内容与摄影（模板用 CSS 肌理占位，上线时换真实自然光摄影）。
3. **控制密度**：全页文字 <400 字；每屏一意；空白 ≥50%。
4. **过自检清单**。

## 自检清单

- [ ] 每屏空白 ≥50%；一屏只有一句主文案
- [ ] 全站衬线/明朝体打底，无粗体 700+，无斜体
- [ ] 全站 ≤4 色；印章红面积 ≤32px；没有渐变、阴影、重底色块
- [ ] 圆角 0–2px；竖排每页 ≤2 处、每处 ≤12 字，正文横排
- [ ] 细线全部 1px 同色温；层级靠留白与字距
- [ ] 全局有 3–6% 纸纹肌理；摄影是自然材质空景（模板中的 CSS 占位已替换）
- [ ] 动效 ≥400ms、ease-out 淡入、无弹跳、无自动轮播
- [ ] 没有樱花/灯笼/和服贴纸等符号化假和风
- [ ] 移动端正文横排、竖排 ≤2 列、行高 ≥1.9、正文 ≥15px
