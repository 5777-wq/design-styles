# 瑞士风格的色彩系统、视觉语言与动效

> 来源：Smashing Magazine、Aesthetary、Print Magazine、SwissThemes、Vitsœ（Rams 十原则）、Material Design Dark theme、WCAG 对比度计算。

## 一、为什么是「白底 + 黑字 + 一个强调色」

三重来源：**印刷经济**（每多一色多一块版费，海报惯用 1–2 个专色叠黑）、**客观性信条**（Müller-Brockmann：设计应像机器一样中立，色彩只承载信息不承载情绪）、**对比即层级**（白底黑字提供最大可读性，强调色是唯一的"音量旋钮"）。注意：史料并不规定"必须红"——M-B 的 1958 海报是绿+蓝；真正的约束是**少量平涂色 + 功能性使用**，红只是最著名的偶然。

## 二、三套完整配色 Token

**方案 A「苏黎世纸白」**——最接近 M-B 音乐厅海报，推荐默认。

| 角色 | 浅色 | 深色 |
|---|---|---|
| 背景 | `#F7F6F2` 暖纸白 | `#131312` 暖炭黑 |
| 表面/图版 | `#FFFFFF` | `#1C1C1A` |
| 前景 | `#111111` | `#EAEAE6` |
| 次级文字 | `#4A4A45`（约 8.5:1） | `#A8A8A2`（约 7.5:1） |
| 弱化标签 | `#6E6E67`（≥4.5:1，仅小标签） | `#8A8A83` |
| 分隔线 | `#DEDDD5` | `#2E2E2B` |
| 强调色 | 瑞士红 `#E30613`（白底约 4.9:1） | 国际橙 `#FF4F00`（深底约 5.7:1） |

**方案 B「巴塞尔画廊」**——Hofmann 式极冷、最硬朗。

| 角色 | 浅色 | 深色 |
|---|---|---|
| 背景 | `#FFFFFF` | `#121212` |
| 前景 | `#0A0A0A` | `#E6E6E6` |
| 次级 | `#3D3D3D` | `#A3A3A3` |
| 弱化 | `#6B6B6B` | `#8C8C8C` |
| 分隔线 | `#E4E4E2` | `#303030` |
| 强调色 | 克莱因蓝 `#002FA7`（约 10.7:1） | `#4D6FE3` 或 `#7A9BFF` |

**方案 C「信号工坊」**——工业感（瑞士航空/交通遗产）。浅色：背景 `#F2F2EF` / 前景 `#0E0F10` / 次级 `#43464A` / 弱化 `#66696C` / 分隔线 `#CFCFC9` / 强调 `#B02A10`（5.9:1）。深色：背景 `#141414` / 前景 `#E8E8E4` / 分隔线 `#2F2F2F` / 强调 `#FF4F00`。

**深色模式不是反色**：背景用深灰不用 `#000`（纯黑产生光晕 halation）；文字用 `#E0E0E0` 级不用纯白；强调色上移提亮并降饱和以过 4.5:1；**保留网格、hairline 与编号秩序**——深色下尤其依赖规则线维持结构可见性；禁止霓虹发光。做到这五点，深色瑞士模式比浅色更接近画廊射灯效果。

## 三、灰阶层级

- **层级主要不靠灰度，靠字重 + 字号 + 位置**：至少两个信号同时作用（次级文字 = Medium/Regular + 小 1–2 档字号，灰度只做辅助）。
- **灰度下限即对比度下限**：白底次级文字不得浅于 `#6B6B6B`（4.5:1）。"白底浅灰小字"是头号廉价错误——用**带色温的灰**（暖白底配暖灰 `#4A4A45`）比纯中性灰更贵。
- **分隔线 = 背景色 darken 8–12% 的同色温灰**（纸白底 `#DEDDD5`），永远 1px；分隔线深于次级文字是错误。

## 四、视觉语言硬规则（8 条）

1. **radius = 0，全局直角**。圆角是消费级柔和装饰信号。
2. **细规则线只许"分隔"，不许"装饰"**：只用它划分网格区域；卡片用单条顶部规则线而非四边框；四边框+阴影 = 模拟物理高度 = 非瑞士。漂浮在空白里的装饰线是最大反例。
3. **色块必须平涂且功能性**（状态、强调、图版），禁止色调渐变面板和 10% 透明度"假色块"。
4. **强调色上限一个，占屏 <5%**：链接、当前态、索引标记、关键数据。出现第二个色相即破功。
5. **摄影 = 客观记录**：正面拍摄、无滤镜无双色调、裁切为网格模数整数倍、贴边放置（出血到列边界）；黑白/去饱和常用，但目的是纪实不是"风格滤镜"。
6. **不对称构图、齐左不齐右**；居中大标题是"非瑞士"最强信号（例外：图注、数据标注）。
7. **数字与索引用 tabular figures**；编号与正文同字号或略小、同灰度，靠位置制造秩序；表格只用横线。
8. **空白是网格量**：间距取 8px 基准刻度且为模数整数倍，行高取模数一半的倍数——任意值留白即失序。

## 五、动效规范

**允许**：
- 颜色状态变化：100–120ms，linear
- 下划线从左展开 / 1px 规则线变强调色：120ms，linear
- 沿网格轴的整数模数位移（如 translateX(8px)）：200ms，`cubic-bezier(0.25, 0, 0, 1)`
- 透明度淡入淡出：150ms，linear
- 手风琴/列表重排：240–300ms，同 bezier
- 悬停可字重 400→500 或背景反转（黑底白字 invert）

**禁止**：弹跳/回弹；任何 scale 缩放（含卡片 hover 放大）；旋转；blur；发光/阴影浮现；视差滚动；默认入场动画；>400ms 的长缓动。

**底线**：动效完全可选，必须尊重 `prefers-reduced-motion`（降级为瞬时或纯透明度）。

## 六、反模式与高级感

**反模式**（网格+无衬线之外再加任何一个第二装饰信号，就不是瑞士了）：渐变；投影与玻璃拟态；圆角滥用；居中排版；彩虹配色/多强调色；大阴影悬浮卡片；装饰性图标堆砌。

**避免"性冷淡→廉价"**：廉价感来自"删完就结束"。结构必须**可见**（规则线、编号、网格对齐），全部藏起来就只剩模板感；删掉后可读性下降的元素必须加回。

**高级感的 5 个来源**：
1. 留白尺度——板块间距取卡片内边距的 2–4 倍，"先给空间、内容来挣位置"。
2. 字号对比的胆量——数学字阶、单一字族 2–3 字重、45–75 字符行长；极端字号对比是核心。
3. 细节精度即尊重（Rams 第八原则）——1px 就是 1px、基线严格对齐、tabular 数字右对齐。
4. 色彩的稀缺纪律——一个强调色的克制使用制造"每次出现都有分量"。
5. 诚实与客观（Rams：不夸大、不虚假承诺）——真实摄影、无效果堆砌，个性体现在清晰与节奏。
