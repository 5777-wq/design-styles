# 瑞士风格网页版式模式与真实案例

> 来源：swissthemes.design 站点拆解、SiteInspire「Swiss」分类、Awwwards minimal/typography 分类、实测站点（edvardscott.com、norgram.co、grapa.studio、vitsoe.com、lineto.com）、Smashing Magazine。

Awwwards/SiteInspire Swiss/minimal/typographic 类获奖站共性：**文字即界面 + 行式列表 + 单强调色 + 至多一个表达性动效**。

## 二、8 个版式套路（含参数）

1. **固定顶栏：词标 + 编号词表导航**。左上 wordmark（16–18px 加粗），右上 3–5 个菜单项，每项前缀编号「01 / 02 / 03」，字号 12–14px，letter-spacing 0.02–0.05em。导航就是一行文字——不做胶囊按钮、不加背景色。
2. **Hero = 超大左对齐标题 + 微距说明**。主标题 clamp(48px, 9–10vw, 160px)，line-height 0.95–1.05，仅 1–2 个字重；配 12px 大写微标签（如「PORTFOLIO — 2026」）。整页最大的视觉元素就是文字本身。
3. **微标签 / 索引号系统**。全站统一用「(01)」「SEC. 02」式编号；10–12px、大写、letter-spacing 0.05–0.1em、颜色为正文的 50–60% 灰。用于区块标题上方、列表行首、图片角标。
4. **细分隔线代替卡片**。1px 实线、黑色 10–20% 透明度；用于列表逐行分隔、导航下方、页脚上方。区块之间靠「线 + 大留白」。
5. **行式列表**：「年份 | 标题 | 类目」三栏行式，行高 56–72px，hover 整行变色或标题右移，不依赖缩略图；数据/服务列表同理（编号 + 名称 + 一句话描述）。
6. **网格与留白**：桌面 12 栏、gutter 24–32px、页边距 32–64px、容器 1200–1440px；非对称分栏 4/8 或 5/7；间距只用 4 的倍数（8/16/24/32/48/64/128），section 间距 64–128px。
7. **字阶数学比率**：1.25 或 1.333 倍率，正文 16–18px/1.5–1.6；全站 1 个字族 2–3 个字重；左对齐 ragged right。
8. **色彩纪律**：黑白 + 一个功能性强调色（仅 hover、当前态、单个色块）；每站只允许一个「表达性姿态」（一个网格揭示动效、一种图片位移），其余全部克制。

**页脚公式**（各案例高度一致）：2–4 栏小字区——联系方式（邮箱可放大为可点击项）/ 邮政地址 / 社交链接词表 / colophon（©年份、所用字体、制作署名）；顶部压一条 1px 分隔线；字号 12–14px；全站最安静的区域。

## 三、移动端降级策略

1. **塌缩为单列时保留阅读顺序与层级**：标题-微标签-正文的先后关系不变；行式列表降级为「标题+年份」两行式，年份做成 10–11px 上标位。
2. **编号导航降级为全屏覆盖菜单**，菜单项反而放大为 hero 级字号（40–60px），编号保留——瑞士站移动端最有辨识度的处理。
3. **字号用 clamp() 流式缩放**；行式列表行高从 64px 收到 48–56px；**分隔线、微标签体系原样保留**（它们不占空间，是风格的最低成本载体）。
4. **断点按内容定**：约 640px（1 栏）、1024px（6–12 栏）；禁止为省空间牺牲对比度（不用浅灰小字）或隐藏全部导航。
