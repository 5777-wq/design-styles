# 构成主义研究笔记（Russian Constructivism → 网页 UI）

> 来源：Tate、The Art Story（Constructivism / Rodchenko）、MoMA 与芝加哥艺术学院（About Two Squares）、Tupitsyn《Gustav Klutsis and Valentina Kulagina》、Harvard 展页、ParaType/Adobe「Rodchenko」字体档案、Beat Film Festival 案例、clippy。

## 一、起源与正典

约 1915 年由 **Tatlin 与 Rodchenko** 开创（Tatlin 受毕加索立体主义构成启发转用工业材料）；从 Malevich 至上主义中分化出**实用方向**——至上主义求纯粹几何的精神感受，构成主义求「艺术进入生活」：十月革命后成为官方先锋语言，经 Agit-Train（宣传列车）向识字率低的农村传播。1921 年「5×5=25」展上 Rodchenko 宣告「绘画之死」转向工业实用美术；1923 年 LEF 宣言「以对象的材料构成取代审美组合」。传播链：Lissitzky 在魏玛德国活动，直接喂养包豪斯（Moholy-Nagy 本身即构成主义阵营人物）。1930 年代初被社会主义现实主义取代；Klutsis 1938 年死于大清洗。**VKhUTEMAS**（莫斯科高等艺术与技术工作室，1920–1930）是官方学院。

正典作品：
- **Lissitzky《以红楔攻打白军》**（1919–20）：红楔自左下刺入右上白色圆——楔形 = 方向性力量，斜线 = 冲突轴；《Proun》系列 =「从绘画转向建筑的车站」；《关于两个平方的故事》(1922/23)：红黑两方「建构世界」，结尾号召「去构造吧」——号召式排版的源头。
- **Rodchenko**：《Lengiz「书！请用一切知识领域的书」》(1924，Lili Brik 呐喊头像 + 口号)；Mosselprom 海报；《Dynamo 俱乐部》海报（1923，几何大写无衬线）；摄影以极端仰俯角、生硬裁切著称。
- **Klutsis**「苏联照片蒙太奇之父」与 **Kulagina**：合作约 150 件海报，把自己扮成工人剪入画面。**Stepanova**：织物纹样与运动服、《第一个五年计划之成果》(1932)。

## 二、三运动判据（与合集内 bauhaus 的分界）

| 判据 | 构成主义 | 包豪斯 | De Stijl |
|---|---|---|---|
| 轴线 | **对角线主导**（动态） | 网格 + 部分对角，功能优先 | **严格正交**，只有横竖 |
| 色彩 | **红 + 黑 + 米白**（政治红） | 三原色 + 几何，理性分配 | 三原色 RYB + 黑白，非对称平衡 |
| 图像 | 照片蒙太奇、楔形、箭头 | 几何形构成 | 无图像，纯抽象 |
| 情感 | 政治热情、动员 | 理性、标准化 | 静态、精神平衡 |

速查：页面主轴一旦倾斜 → 构成主义；红色从「分配角色」变成「进攻方向」→ 构成主义；出现蒙太奇人像剪影 → 只可能是构成主义。

## 三、12 条硬规则（每条一句为什么）

1. **每屏必须有一条对角线元素**（色带/文字块/分割线）——对角动态是身份，横平竖直即退化为包豪斯。
2. **主色只有红黑米白三种，红色占比 ≤30%**——红在原作中是「插入的楔子」，铺满即失去攻击性。
3. **一个视口只允许一个主斜向**（其余元素与其平行或正交）——Lissitzky 力场理论：形状之间要有方向关系。
4. **标题必须超粗、全大写、紧字距**（weight 800–900）——Dynamo 海报字体的直接后裔，细字重立即穿帮。
5. **旋转角度只能取 15°/30°/45°**——原作斜线均可归约为这几个角度，任意角度会变「卡通倾斜」。
6. **摄影必须处理**：灰度化 + 高对比裁切（头部近景、极端视角），禁止原色照片。
7. **口号以条状色块承载，独占一行，禁止藏在段落里**——原典功能是 agitprop，号召必须喊出来。
8. **红色必须「楔入」其他形状**（穿插、切进、压角），不许孤悬留白中——原作语法是冲突与穿透。
9. **等宽字体只用于年代/坐标/编号注记**——模拟档案标签，不参与正文层级。
10. **禁止渐变、圆角超过 8px、投影柔光**——印刷时代的锐利边缘是材料诚实的数字对应。
11. **每页至多一个 starburst 徽章、一处竖排文字**——母题复数化即变贴纸拼盘。
12. **历史注记用作品名 + 年份锚定语境**——声明这是设计史引用而非政治表达。

## 四、设计 Token

**配色 A：正典红黑（报纸底，默认）**：墨 `#141414` / 米白 `#F2E9DC`（报纸感，禁纯白 #FFF）/ 正典红 `#CE2B37` / 高亮红 `#D42B1E`（hover/徽章）/ 印刷灰 `#8A8378`。
**配色 B：深蓝工装**：红 `#D42B1E`、黑 `#141414`、底 `#EFE7D3`、**深蓝 `#1F3A5F`**（替代 60% 的黑用于大面积色块）、砖橙 `#C4622D`（<5%）。深蓝适合多页文档站，红黑适合单页海报型。

**字体（Google Fonts）**：展示 `Archivo Black`（Dynamo 粗黑气质）；备用 `Bebas Neue`（高瘦大写，竖排口号最佳）；次级 `Oswald` 500–700；正文 `Inter` 400/600；中文 `Noto Sans SC` 900（标题）+ 400（正文）——900 字重才压得住俄式海报墨量；等宽注记 `Space Mono` / `JetBrains Mono`，全大写 11–12px、0.08em。

**对角角度体系**：15° = 文字块/标签（可读性优先）；30° = 主标题与 hero 色带（默认斜向）；45° = 楔形、箭头、分割锐角（仅短元素）。同一页主斜向取其一，副元素平行之。

**粗线与色带**：规则线 3px（黑）；强调线 6–8px；「构造梁」12–16px 色带可承载文字；色带高 ≥56px 时内文允许旋转 −30°；分割楔形高 80–140px。

## 五、版式模式（7 个）

1. **对角 Hero**：米白底；左下→右上 30° 红色带（高 120–160px、宽 120%、left:-10% 出血）；主标题叠于带上沿同角度旋转；右下角一枚 45° 黑楔（clip-path 三角）反向插入红带——复刻红白冲突。标题 clamp(48px, 9vw, 120px)。
2. **楔形分割带**：`clip-path: polygon(0 0, 100% 0, 100% calc(100% - 90px), 0 100%)` 或 skewY(-4deg) 色带制造斜切边界；双色相邻时楔尖互相咬合 20–40px。
3. **蒙太奇人像**：照片 `filter: grayscale(1) contrast(1.35)`；`mix-blend-mode: multiply` 压在米白底上；背后错位 8–12px 放同尺寸红/黑色块（印刷套版错位感）；容器旋转 −15°，配 Space Mono 图注「FIG. 01 · 1924」。
4. **竖排口号条**：左/右固定 64–88px 宽黑条，`writing-mode: vertical-rl` 全大写 Bebas Neue/Oswald 红字——海报左缘标语栏，也是移动端保留的最小装饰。
5. **大写口号条（Marquee）**：整宽红色横条，Oswald 700 大写白字，字间 ◤/★ 分隔；静态或极慢滚动（60s/循环）。
6. **Starburst 徽章**：clip-path 12–16 齿，直径 120–180px，红底米白字，中心写号召词（「开幕」「早鸟」），可整体旋转 15° 压在标题一角；每页至多一枚。
7. **构造网格 section**：卡片不用阴影，用 3px 黑描边矩形 + 左上角红色序号方块（60×60px 白色编号）；不等宽列（1fr/2fr）错位排列，留出「力场」缺口。

## 六、动效

**允许**：hover 色块/徽章整体旋转 ±5–15°；楔形入场一次到位（0.3–0.4s ease-out）从 0 平移刺入；口号条 60s 匀速循环；链接 hover 黑红反转（无过渡或 0.1s，硬切更印刷）；滚动显现整块硬切而非淡入。
**禁止**：视差滚动、spring/bounce、模糊、发光、粒子、鼠标跟随、超过 0.5s 的缓动——动态感来自「方向与速度的暗示」（构图本身就斜），不来自物理动画。

## 七、移动端

1. 对角 hero 斜带改浅（高 80–100px、角度 15°），旋转标题保持但字号下限 40px。
2. 竖排口号条保留（改 static 不固定），性价比最高的风格签名。
3. 双栏蒙太奇改单列，套版错位 12px→6px，防横向滚动。
4. 楔形分割高度减半（90→48px），防斜边裁字。
5. 禁用 marquee 的 hover 暂停逻辑，touch 端慢速滚动或静态。

## 八、反模式与政治符号边界

廉价化路径：红五星 + 锤子镰刀 + 俄文字母乱贴（不懂俄语者常拼出错词）+ 做旧纹理 + 渐变 =「苏联纪念品商店」而非构成主义。
边界建议：**用于文化节、影展、出版、建筑导览等历史/文化主题时成立**；元素选取用「抽象几何母题」（楔、圆、斜带、蒙太奇）而非「国家符号」（锤镰、军徽、领导人像）；避免当代政治争议的配色拼接；页面保留「风格出处注记」既加分又免责。史实红线：Klutsis 等人死于该体制——不应把「宣传机器」浪漫化为纯美学。

## 九、示范页内容方案

**「斜线国际独立出版市集」DIAGONAL ZINE FAIR**：对角 Hero（红 30° 色带承载主标 + 副题「DESIGN AS CONSTRUCTION · 印刷即构造」+ 右下黑楔嵌日期 + starburst「早鸟票」压角）；口号条「去构造吧！ GO AND CONSTRUCT — 利西茨基，1922」；展签网格（12 家出版社卡：黑描边 + 红序号方块 + 「STALL 01–12」等宽注记）；蒙太奇区（3 位驻场艺术家，灰度高对比人像 + 红黑错位块 + FIG 注记）；竖排栏「印刷工坊日程」；楔形分割 → 议程时间轴 → 票务 CTA 大色块（黑底红字，hover 硬切反转）→ 页脚出处注记「本站视觉方法源自俄国构成主义，1915–1932」。
