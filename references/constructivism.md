# 构成主义风格网页设计 (Russian Constructivism)

## 风格本质

一句话：**红黑米白的对角动员令——楔形刺入、口号怒吼、蒙太奇人像，构图本身就是冲力。**

约 1915 年由 Tatlin 与 Rodchenko 开创，从至上主义分化出「艺术进入生活」的实用方向；El Lissitzky 的《以红楔攻打白军》(1919) 确立楔形与斜线的语法，Klutsis 夫妇确立照片蒙太奇。它经 Lissitzky 直接喂养了包豪斯，是三支现代主义里最「热」的一支。

**适用**：文化节、影展、独立出版/市集、音乐节、倡议活动、建筑导览——历史/文化主题的动员型页面。
**不适用**：企业官网、金融医疗、需要「中立客观」的页面（这份热情会烧到内容）。

## 与 bauhaus / de-stijl 的分界（同 skill 族的判据）

| 判据 | 构成主义 | 包豪斯 | De Stijl |
|---|---|---|---|
| 轴线 | **对角线主导** | 网格 + 部分对角 | 严格正交 |
| 色彩 | 红+黑+米白 | 三原色几何 | 三原色 RYB+黑白 |
| 图像 | 蒙太奇、楔形、箭头 | 几何构成 | 无图像 |

速查：主轴一倾斜 → 构成主义；红色从「分配角色」变成「进攻方向」→ 构成主义；出现蒙太奇人像 → 只可能是构成主义。

## 十二条铁律

1. **每屏必须有一条对角线元素**——对角动态是身份，横平竖直即退化为包豪斯。
2. **主色只有红黑米白三种，红色 ≤30%**——红是「插入的楔子」，铺满即失去攻击性。
3. **一个视口只允许一个主斜向**，其余元素与其平行或正交——力场理论。
4. **标题超粗、全大写、紧字距**（weight 800–900）——细字重立即穿帮。
5. **旋转角度只取 15°/30°/45°**——任意角度会变「卡通倾斜」。
6. **摄影必须灰度化 + 高对比裁切**，禁止原色照片。
7. **口号以条状色块承载，独占一行**——号召必须喊出来。
8. **红色必须「楔入」其他形状**——穿插、切进、压角，不许孤悬留白。
9. **等宽字体只做年代/坐标/编号注记**——档案标签，不进正文层级。
10. **禁渐变、圆角 >8px、投影柔光**——锐利边缘是材料诚实。
11. **每页至多一枚 starburst、一处竖排**——母题复数化即贴纸拼盘。
12. **历史注记用作品名 + 年份锚定语境**——设计史引用，非政治表达。

## 设计 Token 速查

**配色 A「正典红黑」（默认）**：墨 `#141414` / 米白 `#F2E9DC` / 正典红 `#CE2B37` / 高亮红 `#D42B1E` / 印刷灰 `#8A8378`。
备选 B「深蓝工装」：底 `#EFE7D3` + 深蓝 `#1F3A5F`（大面积替代黑）+ 红 `#D42B1E` + 砖橙 `#C4622D`（<5%）。

**字体**（Google Fonts）：展示 `Archivo Black`；竖排口号 `Bebas Neue`；次级 `Oswald`；正文 `Inter`；中文 `Noto Sans SC` 900/400；等宽注记 `Space Mono`。
引入：`family=Archivo+Black&family=Bebas+Neue&family=Oswald:wght@500;700&family=Inter:wght@400;600&family=Space+Mono&family=Noto+Sans+SC:wght@400;900`

**角度体系**：15° 文字块 / 30° 主标题与 hero 色带（默认）/ 45° 楔形箭头（仅短元素）。同页一个主斜向，副元素平行。
**线条与色带**：规则线 3px；强调线 6–8px；构造梁色带 12–16px；楔形分割高 80–140px。

## 工作流程

1. **选配色**：A 红黑（海报型单页）或 B 深蓝工装（多页文档型）。
2. **从模板起步**：复制 `assets/templates/constructivism.html`（虚构「斜线国际独立出版市集」示范页），替换内容。
3. **组装模式**：对角 Hero → 口号条 → 展签网格 → 蒙太奇区 → 楔形分割 → 时间轴 → 票务 CTA → 出处注记页脚。
4. **过自检清单**，特别核对政治符号边界（用抽象几何母题，不用国家符号）。

## 自检清单

- [ ] 每屏有一条对角线元素；全页只有一个主斜向（15°/30°/45° 体系内）
- [ ] 全页只有红黑米白三色；红色 ≤30% 且每处都「楔入」其他形状
- [ ] 标题全部 800–900 字重大写；正文干净；等宽字体只做注记
- [ ] 照片全部灰度高对比处理 + 套版错位色块
- [ ] 口号在条状色块里独占一行；没有藏在段落里的号召
- [ ] starburst ≤1 枚、竖排 ≤1 处；无渐变、无大圆角、无柔光投影
- [ ] 动效只有硬切入场/黑红反转/慢速口号条；无弹跳无发光
- [ ] 没有锤镰/军徽/领导人像等国家符号；页脚有风格出处注记
- [ ] 移动端斜带变浅、竖排保留、楔形减半、无横向溢出
