
# 玻璃拟态风格网页设计 (Glassmorphism)

## 风格本质

一句话：**材质本身即视觉主角——半透明玻璃面板悬浮在彩色光斑之上，靠折射与景深制造高级感。**

谱系：Windows Vista Aero（2006）→ Fluent Acrylic/Mica（2017/2021）→ iOS 7 vibrancy → **macOS Big Sur / iOS 14（2020）大众化** → Malewicz 2020 年正式命名，Dribbble 热潮 → 2025 Apple Liquid Glass 再度点燃。当下的共识是克制使用：玻璃只作局部材质，不作全局皮肤。

**适用**：音乐流媒体、天气、钱包/支付卡、媒体库、地图等情绪化、图形化、文字量少的产品。
**不适用**：文档、新闻长读、法律条款、电商结算等文字密集场景——**文字密度与透明度成反比，一屏正文超过 150 字就该退回实色面板。**

## 十二条铁律

1. **玻璃必须有彩色衬底**：玻璃的本质是「折射背后的东西」，纯色/白底上玻璃退化为半透明灰块，视觉不存在。
2. **一屏最多 1–2 层玻璃面板**：多层玻璃互相叠加会摧毁景深层级，blur 开销也随层数倍增。
3. **承载正文的面板底色必须提浓**（rgba 白 0.6–0.85，参考 Apple 导航栏 0.72）：只有高不透明度才能保证 WCAG 4.5:1。
4. **纯装饰面板才允许 0.08–0.25 低不透明度**：无文字的玻璃才有资格「薄」。
5. **永远用 backdrop-filter 而非 filter**：filter 会把面板自己的文字一起糊掉。
6. **blur 配 saturate(160%–180%)**：纯 blur 让透过的内容发灰发闷，饱和度补偿是 Apple 玻璃「鲜活感」的关键。
7. **必须有 1px 白色半透明描边 + 顶部亮边**（inset 0 1px 0 白 0.4–0.5）：描边模拟玻璃厚度与受光边缘，没有它面板像果冻而非玻璃。
8. **模糊半径 8–24px 区间**：低于 8px 背景可辨识导致文字脏；NN/g 明确「宁多勿少」，复杂背景取 20px+。
9. **背景光斑必须大而软**（blur 80px+、直径 40–60vw）：硬边色块透过玻璃会形成干扰纹理。
10. **文字永远实色高对比**（深底白字/浅底黑字）：文字本身不允许做透明或发光处理。
11. **@supports + prefers-reduced-transparency/motion 双降级**：无 backdrop-filter 的浏览器拿近实色面板；要求降透明的用户拿无模糊面板。
12. **玻璃只给「情绪层」，不给「信息密集层」**：表格、长文、表单用实色底，玻璃只包裹短标签、卡片头、导航。

## 设计 Token 速查

**背景光斑配色（3 套）**：

| 主题 | 基底（linear-gradient 135deg） | 光斑 blob（radial + blur 80–100px） |
|---|---|---|
| A 深空紫蓝（默认） | `#0F0C29` → `#302B63` → `#24243E` | `#7B2FF7` / `#00C2FF` / `#FF6EC7`，各 40–55vw，透明度 0.35–0.5 |
| B 午夜蓝绿 | `#0B1026` → `#101A3D` | `#00E5C3` / `#4F46E5` / `#2563EB`，透明度 0.3–0.45 |
| C 浅色系 | `#EEF2FF` → `#FDF2F8` | `#A5B4FC` / `#67E8F9` / `#FDA4AF`，透明度 0.5–0.6 |

光斑布局：2–3 个，错落对角（左上/右下），彼此不完全重叠，底层压深色 vignette 防边缘漂白。

**玻璃面板参数表**：

| 变体 | background | backdrop-filter | border | 阴影 |
|---|---|---|---|---|
| 薄玻璃（装饰/悬浮卡） | rgba(255,255,255,**0.10–0.15**) | blur(16–20px) saturate(180%) | 1px solid rgba(255,255,255,0.25–0.3) | 0 8px 32px rgba(0,0,0,0.10) + inset 0 1px 0 rgba(255,255,255,0.4) |
| 厚玻璃（导航/承载文字） | rgba(255,255,255,**0.72**)(浅底) 或 rgba(15,12,41,**0.6–0.75**)(深底) | blur(20px) saturate(180%) | 1px solid rgba(255,255,255,0.2) | 0 4px 24px rgba(0,0,0,0.12) |
| 玻璃胶囊（按钮/badge） | rgba(255,255,255,0.18) | blur(12px) saturate(170%) | 1px solid rgba(255,255,255,0.35) | 0 2px 12px rgba(0,0,0,0.10) |

参数出处：hype4 玻璃生成器默认值 + Apple 官网导航实测（saturate(180%) blur(20px) + rgba(255,255,255,0.72)）。Safari 必须写 `-webkit-backdrop-filter`。

**字体**：`Inter`（正文，最接近 SF Pro）+ `Space Grotesk` 或 `Outfit`（Display）。Display 600–700，正文 400–500，标题 -0.02em。
**圆角**：badge/输入框 12px；卡片 16–20px；大卡/模态 24–28px；胶囊 999px。blur 越大圆角越大；同屏 ≤3 档。

## 工作流程

1. **选场景**：确认产品属于「情绪层」（可用玻璃）还是「信息密集层」（退回 swiss-design 等）；选定光斑配色 A/B/C。
2. **从模板起步**：复制 `assets/templates/glassmorphism.html`（虚构音乐流媒体 Aurora FM 示范页，含磨砂导航、光斑 hero、悬浮部件群、玻璃卡全套与降级方案），替换内容。
3. **校验对比度**：所有玻璃上的文字按最差局部背景校验 WCAG 4.5:1；正文面板一律厚玻璃。
4. **过自检清单**。

## 自检清单

- [ ] 背景有 2–3 个大而软的彩色光斑；没有纯白/纯黑无衬底的玻璃
- [ ] 一屏玻璃面板 ≤2 层；没有玻璃套玻璃嵌套
- [ ] 承载正文的面板不透明度 ≥0.6；纯装饰面板才 ≤0.25
- [ ] 用的是 backdrop-filter（不是 filter），且配 saturate(160–180%)
- [ ] 所有玻璃有 1px 白半透明描边 + 顶部亮边
- [ ] blur 在 8–24px；文字实色高对比，没有透明/发光文字
- [ ] 有 @supports 降级（近实色面板）+ prefers-reduced-transparency/motion 豁免
- [ ] 光斑动画 30–60s 极慢，没有 blur 值过渡动画
- [ ] 移动端 blur ≤16px、单屏玻璃 ≤2、Safari 有 -webkit- 前缀
