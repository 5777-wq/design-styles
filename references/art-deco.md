# Art Deco 风格网页设计 (装饰艺术)

## 风格本质

一句话：**对称的几何奢华——深哑光底、金线描边、阶梯与旭日纹，把摩天楼立面的仪式感搬进网页。**

1925 年巴黎「现代工业与装饰艺术国际博览会」得名（1966 年回顾展后定名）。正典：Cassandre 的《Normandie》海报、克莱斯勒大厦的阶梯退台、迈阿密海滩的流线立面、Ruhlmann 的家具。它是合集里**唯一天然对称**的风格——正面性 (frontality) 就是它的识别性。

**适用**：奢华酒店、爵士酒吧/俱乐部、珠宝、电影院、餐厅、婚纱级活动页。
**不适用**：工具类 SaaS、资讯阅读、儿童品牌（仪式感错位）。

## 十二条铁律

1. **一切对称**：版面默认左右镜像居中，居中轴线必须存在且唯一；不对称即现代主义。
2. **深哑光底 + 小面积金线**：金是「描线」不是「填色」，金占画面 ≤10% 才贵；满屏金字 = 婚庆 PPT。
3. **只用几何装饰，禁用有机卷草**：藤蔓涡卷花体属于 Art Nouveau，是混种信号。
4. **细线是骨架**：分隔、边框、饰带用 1px hairline 多重嵌套；粗黑边属于 Neubrutalism。
5. **阶梯代替曲线**：转折用 45° 斜切或直角退台 (ziggurat)；无软糖圆角。
6. **大写 + 宽字距做展示体**：全大写几何体，letter-spacing 0.12–0.25em。
7. **最多两套字族**：一个几何展示体 + 一个正文体；展示体只做标题。
8. **配色限三方**：深底 + 珠宝色（翡翠/宝蓝/酒红）+ 金，外加米白文字；每页 ≤4 色。
9. **垂直分层像建筑立面**：等宽分栏 + 栏间细线，模拟摩天楼窗格；栏内禁止再分栏。
10. **摄影必须处理**：降饱和/黑白 + 细金框装裱，原图直出破坏雕平质感。
11. **留白也是材料**：奢华来自空旷大堂的比例感。
12. **动效克制对称**：只允许中轴对称展开、缓慢线条生长、极慢旭日旋转；禁弹跳/3D/霓虹闪烁。

## 设计 Token 速查

**配色 A「午夜翡翠」（默认）**：深底 `#0D0D0F` / 卡面 `#16161A` / 翡翠 `#0F5132`（亮态 `#1E7A46`）/ 金线 `#D4AF37`（高光 `#E8C878`）/ 香槟米白 `#F2E8D5`。
备选：B「宝蓝爵士」`#0A1128` + `#2B4C8C` + 古金 `#C9A227`；C「迈阿密流线」奶油底 `#F7EFE2` + 焦橙 `#C1622B` + 铜棕 `#B08968`。

**字体**（Google Fonts）：品牌字 **Limelight**；装饰副标 **Poiret One**（只大号）；正文衬线 **Cormorant Garamond**；正文无衬线 **Jost**；标签/票务 **Oswald**。
引入：`family=Limelight&family=Poiret+One&family=Cormorant+Garamond:ital,wght@0,400;0,600;1,400&family=Jost:wght@300;400;500&family=Oswald:wght@500`

**字阶**：品牌字 72–120px；H1 48–72px；H2 32–40px 全大写；eyebrow 13–14px / Oswald / 0.3em；正文 17–18px / 1.7。展示体宽字距 0.12–0.25em。

**细线体系**：单线 1px；双线框 = 外 1px + 内 1px 间隔 4–6px；重要卡三线（1px/2px/1px）；四角饰件 8–12px 菱形 ◆ 或直角折线；人字纹衬带 8–12px 高。

**旭日纹 CSS**：`repeating-conic-gradient(from -90deg, gold 0deg 4deg, transparent 4deg 12deg)` + `mask-image: radial-gradient(closest-side, black 30%, transparent 72%)`。

## 工作流程

1. **选配色**：A 午夜翡翠（默认）/ B 宝蓝爵士 / C 迈阿密流线（浅色变体）。
2. **从模板起步**：复制 `assets/templates/art-deco.html`（虚构爵士俱乐部「鎏金狐」示范页），替换内容。
3. **组装模式**：圣坛 Hero → 立面分栏 → ziggurat 分割带 → Cassandre 海报区 → 票券/菜单块，全程守对称轴线。
4. **过自检清单**。

## 自检清单

- [ ] 中轴线存在且唯一；logo/主标/按钮压轴；栏内容等宽镜像
- [ ] 金只出现在线与饰件上，占屏 ≤10%；没有渐变金字、没有金色大面积底
- [ ] 没有有机卷草/涡卷/花体 script（那是 Art Nouveau）
- [ ] 全部边框与分隔是 1px 级 hairline 及其嵌套；没有粗黑边、没有软糖圆角
- [ ] 展示体全大写且 letter-spacing ≥0.12em；全站 ≤2 字族
- [ ] 每页色彩 ≤4 种（深底 + 珠宝色 + 金 + 米白）
- [ ] 立面分栏等宽、栏间 hairline、栏内未再分栏
- [ ] 照片经过降饱和/黑白处理并装金框
- [ ] 动效只有对称展开/慢速生长/极慢旋转；无弹跳、无霓虹闪烁
- [ ] 移动端：Limelight ≥40px 且字距 ≥0.1em；旭日纹防摩尔纹；触控 ≥48px
