
# 波普艺术风格网页设计 (Pop Art)

## 风格本质

一句话：**把丝网印刷、漫画和超市货架的美学搬进网页——粗黑墨线勾边，高饱和平色填充，冲击力来自撞色与重复。**

源自 1950s 伦敦独立集团与 1960s 美国（Warhol 的丝网复制、Lichtenstein 的漫画放大、Hamilton 的定义「流行的、瞬时的、廉价的、批量生产的」）。网页化的核心母题：粗黑描边、本戴点 (Ben-Day dots)、漫画对话框与拟声词、沃霍尔式重复网格、高饱和撞色。

**适用**：潮流/街头品牌、饮料零食快消、音乐节、游戏、创意机构、DTC 新消费。
**不适用**：金融/医疗/法律等严肃信息站、长文阅读产品、企业级 SaaS——波普的噪音会吞噬信任感与阅读效率。

## 十二条铁律

1. **描边即结构**：所有容器、按钮、图片框用 2–5px 纯黑描边——粗黑墨线是漫画印刷的骨架，去掉它整套语言崩塌。
2. **只用高饱和平色块**，禁渐变、禁灰中间调——波普在模拟丝网印刷，灰尘色让它变脏变旧。
3. **一屏 ≤3 个撞色 + 黑白**——冲击力来自撞色的稀缺席，铺满即灾难。
4. **正文永远黑字浅底**，撞色只给标题、按钮、色块——正文可读性（WCAG 4.5:1）不可让步。
5. **拟声词每页 ≤2 处**，只出现在 hero 与主 CTA——滥用后波普从「态度」降级为「贴纸堆」。
6. **本戴点只做纹理层不承载信息**，dot 直径 ≤ 间距的 1/4——网点密度过高会干扰前景内容。
7. **重复必须成系统**（同图 2×2 / 3×3 换色），禁止随机重复——沃霍尔的重复是对批量生产的陈述，随机只是杂乱。
8. **硬阴影 blur=0，全站同色同向**（如 `4px 4px 0 #111`）——模糊软阴影是拟物语法，会立刻把页面拖回「软糖风」。
9. **展示字体只做短句大字号**（≤8 词、全大写），正文交给中性无衬线——Bangers 类漫画体在 16px 完全不可读。
10. **对话气泡承载真实 UI 文案**（评价、提示、FAQ），不做纯装饰——气泡是波普体系里少有的功能性容器。
11. **图片统一高饱和双色调或半调网点处理**，禁原片直出——连续调摄影与平色块体系相互打架。
12. **动效干脆、有弹性**（150–300ms，允许回弹曲线与 steps 步进）——波普继承漫画的「瞬间性」，慢速优雅淡入不是这里的语法。

## 设计 Token 速查

**配色 A「莉琴斯坦因印刷间」（默认）**：

| 角色 | 值 |
|---|---|
| 背景 | `#FFFDF5` 漫画纸白 |
| 前景/描边 | `#111111` |
| 撞色 1/2/3 | 红 `#E60023` / 黄 `#FFE900` / 蓝 `#002395`（备选：热粉 `#FF1493`、电光青 `#00E5FF`） |

撞色配对法则：撞互补（红绿、蓝橙、黄紫），取色环右上角（高饱和高亮度），永不取灰调。深色模式：bg/fg 互换（`#101010` 底 + 原撞色）。

**字体**（Google Fonts）：

| 场景 | 字体 | 规格 |
|---|---|---|
| display/拟声词 | `Bangers` | clamp(3rem, 8vw, 7rem)，全大写，+0.04em，可用 text-shadow 四向 2px 描字 |
| h1/h2 | `Archivo Black` | clamp(2.25rem→3.5rem)，行高 1.1 |
| 正文 | `Archivo` 400/700 | 16–18px，行高 1.7，中文回退 Noto Sans SC |
| 微标签/价签 | `Archivo` 700 | 0.75rem，全大写，+0.08em |

**描边/阴影/圆角**：

- 描边：主 3px `#111`（卡片/按钮/图框），重 4–5px（hero），细 2px（输入框）
- 圆角二选一：硬朗印刷风 0–2px，或圆润漫画风 12–16px + 气泡 999px；不得混用超过 2 档
- 硬阴影（blur 恒 0）：卡片 `4px 4px 0 #111`；hero `8px 8px 0`；hover `6px 6px` + translate(-2px,-2px)；**active `translate(4px,4px)` 且阴影归零**（按压感）

**本戴点纹理**：`radial-gradient(circle, var(--c) 3px, transparent 3.5px)` + `background-size: 16px 16px`——硬 color-stop 保证边缘锐利，禁止软边 dot。

## 工作流程

1. **定基调**：确认品牌调性选配色方案（A 经典三原色 / B 沃霍尔霓虹 / C 哈林街头 / D CMYK 印刷厂），确认圆角极性（硬朗 or 圆润）。
2. **从模板起步**：复制 `assets/templates/pop-art.html`（气泡水品牌示范页，含爆炸 hero、沃霍尔格、漫画分镜、气泡墙、价签、跑马灯全套），替换内容。
3. **组装模式**：按 references/notes/pop-art.md 的 7 个版式模式拼装；装饰拟声词与爆炸框严格限量。
4. **过自检清单**。

## 自检清单

- [ ] 所有容器有 ≥2px 黑描边；阴影全是硬阴影（blur=0）且同向
- [ ] 没有渐变、没有灰色中间调、没有模糊阴影
- [ ] 一屏撞色 ≤3 个；正文全部黑字浅底，对比度 ≥4.5:1
- [ ] 拟声词/爆炸框全页 ≤2 处
- [ ] 重复元素成系统（网格换色），没有随机贴纸
- [ ] 漫画体只用于大字号短句，正文是中性无衬线
- [ ] 图片经过双色调/网点处理，没有原片直出
- [ ] 动效 150–300ms，允许回弹；无慢速淡入堆叠
- [ ] 移动端描边/阴影降档、网点密度减半、触控目标 ≥44px
