
# 新粗野主义风格网页设计 (Neubrutalism)

## 风格本质

一句话：**「心情很好的朋克摇滚」——精心设计过的故意粗糙：粗黑描边、硬偏移阴影、纯色块，把深度与柔和全部替换为物理感。**

谱系：粗野主义建筑（béton brut 裸露混凝土）→ web brutalism（2015 Bloomberg 报道 Balenciaga「未设计」官网；Hacker News、Craigslist 是「天然粗野」活化石）→ neubrutalism（2021 Gumroad 改版是公认转折点，随后 Figma 社区涌现大量 UI kit，neobrutalism.dev 将其工程化）。

**分界线（必须守住）**：web brutalism 是失控的原始 HTML，无可用性承诺；neubrutalism 是**精心设计的「故意粗糙」**——保留清晰层级、留白、无障碍与交互反馈，只把深度与柔和换成硬边语言。

**适用**：独立开发者产品、创意工具、D2C 潮流品牌、活动/战役页、portfolio、开发者工具。
**不适用**：金融/保险/医疗（信任感）、企业级数据仪表盘、长文阅读产品、奢侈品牌。

## 十二条铁律

1. **描边只用 2/3/4px 纯黑实线**——硬边界是结构语言，1px 细线会退化成普通扁平设计。
2. **阴影 blur 恒为 0**——不透明硬阴影是「贴纸感」的唯一来源，出现模糊即风格崩塌。
3. **阴影方向全局统一右下 45°**——多方向阴影破坏物理隐喻一致性。
4. **禁止一切渐变**——渐变瞬间拉回 2020s SaaS 风，纯色填充是立场。
5. **撞色不超过 4 个色相 + 黑白中性**——高饱和色超过 4 个即视觉过载。
6. **正文永远是深色字 + 米白/白底**——高饱和底色只给小组件和标题块，正文区高饱和底不可读且违反 WCAG 4.5:1。
7. **圆角两极化：全 0 或全大圆角（12–24px），禁 4–8px 中间值**——中间值显得犹豫，破坏「方块=立场」。
8. **hover = 抬起（translate(-2px,-2px) 且阴影加深），active = 按入（位移值=阴影 offset，阴影归零）**——「压进纸面」的物理交互是该风格的灵魂。
9. **层级靠字重、尺寸、边框表达，不靠颜色**——禁止仅用颜色传达状态。
10. **展示字体全大写 + 等宽小标签点缀；正文 ≥16px 中性无衬线**——反叛留在标题，可读性留给正文。
11. **区块留白要慷慨**（区块 padding ≥48px，组件间 16–24px）——粗重块面没有呼吸感会变「脏」而不是「野」。
12. **一切「随意」必须对齐 8px 网格**——不对称是设计出来的聚焦手段，不是失控。

## 设计 Token 速查

**配色 A「经典黄」（默认）**：

| 角色 | 值 |
|---|---|
| 背景 | `#FFFDF5` |
| 主色（CTA/强调块） | `#FFD23F` |
| 撞色 accent | `#FF6B6B`（备选池：`#88D498` 绿 / `#FFA552` 橙 / `#B8A9FA` 薰衣草） |
| 描边/阴影/正文 | `#000000` |

备选：B「橙紫撞色」背景 `#F5F0E6` + `#FF6900` + `#B8B8FF`；C「柠檬天蓝」背景 `#FDF6E3` + `#FFD803` + `#74B9FF`。阴影色恒为纯黑；进阶变体允许「彩色阴影」（阴影色=卡片填充色），但一套页面内二选一。

**字体**（Google Fonts）：Display `Archivo Black`（备选 `Syne` 700–800、`Bebas Neue`）；Heading `Space Grotesk` 500–700；正文 `Inter` 或 `DM Sans`；等宽点缀 `Space Mono` 或 `IBM Plex Mono`（标签/代码/价格）。
引入：`family=Archivo+Black&family=Space+Grotesk:wght@500;700&family=Inter:wght@400;500&family=Space+Mono`

**描边宽度体系**：2px（表内格线）→ 3px（按钮/卡片/输入框，标准值）→ 4px（区块分隔、hero、面板外框）。颜色恒 `#000`。

**硬阴影体系（blur=0，方向恒右下）**：

| 级别 | 值 | 用途 |
|---|---|---|
| sm | `3px 3px 0 0 #000` | badge、chip、小控件 |
| md | `5px 5px 0 0 #000` | 按钮、卡片、面板 |
| lg | `8px 8px 0 0 #000` | hover 态、浮层 |
| xl | `12px 12px 0 0 #000` | hero 元素、对话框 |

**圆角**：默认全 0；若品牌需要亲和力则全站统一 12–24px 大圆角（边框与阴影同步跟随），禁止混用。

## 工作流程

1. **选配色**：A/B/C 三选一，确定描边极性（全直角 or 全大圆角）。
2. **从模板起步**：复制 `assets/templates/neubrutalism.html`（虚构部署工具 Bulldozer 示范页，含硬边框卡片、物理按钮、暴露表格、终端面板全套），替换内容。
3. **组装模式**：按 references/notes/neubrutalism.md 的 8 个版式模式拼装；每个可点元素必须同时有 hover 抬起与 active 按入。
4. **过自检清单**。

## 自检清单

- [ ] 所有描边是 2/3/4px 纯黑实线；阴影 blur=0 且方向统一右下
- [ ] 没有渐变、没有模糊阴影、没有 4–8px 中间态圆角
- [ ] 撞色 ≤4 个色相；正文深色字 on 米白/白底
- [ ] 每个可点元素：hover 抬起（阴影加深）、active 按入（阴影归零）
- [ ] 层级靠字重/尺寸/边框，没有仅靠颜色表达的状态
- [ ] 展示字体全大写；等宽字体做 kicker/label/meta；正文 ≥16px
- [ ] 区块 padding ≥48px，块面之间有呼吸
- [ ] 位移与贴纸旋转都对齐 8px 网格
- [ ] 移动端阴影减半、描边不减、触控目标 ≥44px、:active 等价 hover
