# Mid-Century Modern 风格网页设计 (中古现代)

## 风格本质

一句话：**原子时代的乐观符号学——哑光暖色、有机 blob、星芒与回旋镖，一个图形只说一件事。**

1945–1965 年美国商业设计黄金期。Paul Rand 的「图形即观念」（IBM、ABC、Eye-Bee-M）、Saul Bass 的极简海报（《金臂人》）、Eames 的模压曲线、Alvin Lustig 的抽象书封——把欧洲现代主义翻译成了美国人愿意掏钱买的商业语言。

**适用**：咖啡馆/餐厅、唱片行、复古品牌、创意机构、活动海报页——需要温度与幽默的场合。
**不适用**：严肃金融医疗、极简高冷品牌（→ swiss/japandi）、需要情绪化材质的（→ glassmorphism）。

## 十二条铁律

1. **每屏最多一个装饰母题**（星芒或 blob 二选一）——高级感来自符号经济学，堆叠即「复古贴纸机」。
2. **整页限 4–5 个颜色位**——模拟有限油墨的专色印刷。
3. **所有彩色必须加灰调**（饱和度 45–65%）——50 年代油墨无荧光色。
4. **标题用几何无衬线或粗 slab，正文用中性无衬线**——粗细对比是 50s 编辑排版骨架。
5. **script 手写体全页只许一处**（字标或一句 slogan）——手写体泛滥是复古第一大忌。
6. **blob 用 8 值 border-radius，禁止 morph 动画**——原版是静态丝网印刷图形。
7. **星芒用 clip-path/SVG 纯色绘制，禁渐变**——丝网印刷不存在渐变。
8. **纸纹理仅作噪点叠加**（opacity ≤4%）——负责年代感，不负责抢戏。
9. **构图温和不对称**：60/40 分栏、元素偏置、大量留白。
10. **圆角只有两种语言：全圆胶囊或近直角（≤16px）**——当时不存在「默认 4px 小圆角」。
11. **分割用锯齿边、虚线、打孔线**——继承 diner 菜单与收据的原版语法。
12. **选定一个品牌符号（眼/回旋镖/唱片）贯穿全页**——「设计是品牌的沉默大使」。

## 设计 Token 速查

**配色 A「经典暖调」（默认）**：奶油 `#F5EFE0` / 芥末 `#E3B23C` / 赤陶 `#D96C3F` / 灰蓝 `#5B7C99` / 炭 `#2B2B28`。
备选：B「青绿粉」青瓷 `#2F6F73` + 鲑粉 `#E8A08D` + 芥末 `#D4A437` + 米白 `#E7D8C3`；C「Atomic Era」赤土 `#D97364` + Dutch 白 `#F1E4B7` + 铅蓝 `#83B3AB` + 深蓝黑 `#21233A`。

**字体**（Google Fonts）：display `Jost` 600/700 或粗 slab `Alfa Slab One`；script 点缀 `Yellowtail`（仅一处）；正文 `Inter`；中文 `Noto Sans SC`。
引入：`family=Jost:wght@500;600;700&family=Alfa+Slab+One&family=Yellowtail&family=Inter:wght@400;600&family=Noto+Sans+SC:wght@400;700`

**形状**：blob `border-radius: 30% 70% 70% 30% / 30% 30% 70% 70%`；星芒 clip-path 12 尖（内半径 ≈0.5R）；卡片圆角 20–24px 或 999px 胶囊；打孔边 radial-gradient 圆点列 + 2px dashed。

## 工作流程

1. **选配色与品牌符号**：A/B/C 三选一；从眼/回旋镖/唱片/杯中定一个符号贯穿全页。
2. **从模板起步**：复制 `assets/templates/mid-century.html`（虚构唱片行「Moonbeam Records」示范页），替换内容。
3. **组装模式**：Blob Hero → 星芒公告条 → 菜单卡 → 符号三联卡 → 票券区块 → Albers 宣言区。
4. **过自检清单**。

## 自检清单

- [ ] 每屏只有一个装饰母题；星芒与 blob 没有同屏堆叠
- [ ] 全页 4–5 个颜色位；所有彩色都加了灰调（无荧光色）
- [ ] 手写体只出现一处；标题是几何无衬线或粗 slab
- [ ] blob 是静态 8 值圆角，没有 morph 动画
- [ ] 星芒/图形全部纯色 clip-path 或 SVG，无渐变
- [ ] 纸纹噪点 ≤4%；没有 sepia 全页滤镜
- [ ] 构图温和不对称（60/40），有充足留白
- [ ] 圆角只有全圆胶囊或 ≤16px 近直角，没有 4px 默认小圆角
- [ ] 分割用锯齿/虚线/打孔线；一个品牌符号贯穿全页
- [ ] 动效只有硬阴影位移/极慢自转/淡入；无弹跳无霓虹
